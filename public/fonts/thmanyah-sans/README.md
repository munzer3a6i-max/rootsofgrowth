# Thmanyah Sans font files

The site uses **Thmanyah Sans** (ثمانية) — the typeface used in the Figma design.
Download the family from the official site, **https://font.thmanyah.com**, and review its
licence (https://font.thmanyah.com/licenses) before publishing.

Copy these weights into this folder (either format works — WOFF2 is smaller and preferred):

| Weight  | CSS | WOFF2 file name               | or OTF file name             |
| ------- | --- | ----------------------------- | ---------------------------- |
| Light   | 300 | `thmanyah-sans-Light.woff2`   | `thmanyahsans-Light.otf`     |
| Regular | 400 | `thmanyah-sans-Regular.woff2` | `thmanyahsans-Regular.otf`   |
| Medium  | 500 | `thmanyah-sans-Medium.woff2`  | `thmanyahsans-Medium.otf`    |
| Bold    | 700 | `thmanyah-sans-Bold.woff2`    | `thmanyahsans-Bold.otf`      |
| Black   | 900 | `thmanyah-sans-Black.woff2`   | `thmanyahsans-Black.otf` (optional, not used by the design) |

Rename the downloaded files to match if needed (`thmanyah-sans-Regular.otf` is also accepted),
commit them, and redeploy. Until the files are present the site falls back to Alexandria.
